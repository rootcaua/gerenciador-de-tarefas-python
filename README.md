# Gerenciador de Tarefas em Python

Aplicacao simples de terminal para cadastrar, listar, filtrar, atualizar e deletar tarefas

## Como executar

```bash
python menu.py
```

Tambem e possivel executar diretamente:

```bash
python main.py
```

## Funcionalidades

- Adicionar tarefas com titulo e responsavel.
- Listar todas as tarefas cadastradas.
- Alterar o status de uma tarefa.
- Filtrar tarefas por status.
- Deletar tarefas por posicao.
- Limpar todas as tarefas.

Os dados ficam apenas na memoria enquanto o programa esta aberto.
